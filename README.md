## Dessert Shop Ordering System

A beginner Python project that simulates a dessert shop ordering system through the command line.

## About the project

This programme allows the customer to:
 1) Enter their name
 2) Choose a dessert from the available menu
 3) Select a quantity
 4) Calculate the cost of their order
 5) Place multiple orders
 6) View a final receipt
 7) See their total spending

## Features
 
 1) User input and validation
 2) Lists and dictionaries
 3) `if`, `elif` and `else` statements
 4) `while` and `for` loops
 5) Functions and function parameters
 6) Arithmetic calculations
 7) Order tracking
 8) Receipt generation

## Languages
 
 1) Python
